# RelojUNA - Proyecto de Programación III

## Descripción
Aplicación de reloj marcador para control de asistencia de empleados.

## Arquitectura
- **RelojUNA-Server**: Servicio Web SOAP con JPA (EclipseLink) y Oracle.
- **RelojUNA-Client**: Cliente JavaFX 25+ con MaterialFX, JasperReports y Apache POI.

## Requerimientos Implementados
- [ ] Pantalla de LogIn (Admin)
- [ ] Mantenimiento de Empleados
- [ ] Pantalla de Marcas (Reloj Digital, Animación Cumpleaños)
- [ ] Mantenimiento de Marcas
- [ ] Gestión de Inconsistencias
- [ ] Generación de Planillas (Lógica de horas extra/nocturnas)
- [ ] Consultas con Streams
- [ ] Reportes Excel y Jasper
